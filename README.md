# Passive-Terahertz-Images

**Passive-Terahertz-Images** is a passive terahertz (THz) security-screening image dataset designed for **object detection research**.  
The dataset contains passive THz images with bounding-box annotations for three object categories: **Pistol**, **Knife**, and **Other**.

This dataset is intended to support research on **automated threat detection in passive terahertz security screening systems**.

# Dataset Structure

The dataset contains:

- Passive THz images captured using a passive terahertz imaging system
- Corresponding bounding-box annotations

Class labels:

- `Pistol`
- `Knife`
- `Other`

Annotations provide the spatial location of target objects within each image.

# Intended Use

The dataset is released to support **academic research on terahertz imaging and automated threat detection algorithms**, including but not limited to:

- object detection
- security screening research
- machine learning and computer vision methods for THz imaging

The dataset is **not intended for commercial deployment without permission**.

---

# Ethics and Privacy

All participants involved in data collection were **adult volunteers** who provided **verbal informed consent** prior to data acquisition and were free to withdraw at any time.

The released dataset has been **fully anonymized** and does not contain any direct personal identifiers.  
The images were collected solely for **research purposes related to security-screening algorithm development**.
